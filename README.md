# Julekalender
En julekalender laget på vegne av tverrfaglig uke. Man får spørsmål man svarer på for å delta i en trekning hvor man kan vinne premier. Trekningen for premien skjer hver dag i lunsjen og navnet til brukeren blir ropt opp. Man logger inn med afk posten og navnet sitt.
